# Source and build notes

Tekryno started as separately drawn Illustrator SVG glyph designs, later compiled into TTF/OTF. During development, outline, accent-height, kerning and font-metadata corrections were applied.

**Final source-of-truth:** use the author's last approved Tekryno TTF/OTF, not an earlier Optimus Refined version or a historical SVG builder without comparing the generated result.

An editable UFO source and original SVG archive have been prepared locally for release-candidate review. Before public upload, verify that the UFO rebuild reproduces all intended glyphs, Unicode mappings, advance widths, GPOS kerning and mark positioning, and corrected accented-capital heights.

Expected internal family naming: `Tekryno`, style `Regular`, PostScript `Tekryno-Regular`.

No font binaries, SVG artwork, or license grant have been committed to this repository yet. They will be added after the author's open-source release approval and final quality review.

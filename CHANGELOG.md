# Tekryno — Changelog

## 1.003 — 2026-11-26 (release-candidate build)

- Finalized the **Tekryno** family and `Regular` style names.
- Preserved the angular uppercase-inspired design for both uppercase and lowercase input.
- Corrected uneven accent heights and maintained matching character widths.
- Prepared 218 glyphs and 327 Unicode mappings in both the TTF and OTF release candidates.
- Prepared editable UFO source and Illustrator SVG archives.
- Obtained author approval for public release under SIL Open Font License 1.1 (no Reserved Font Name).

**Release note:** The font files and editable source are in preparation for publication on this GitHub repository. Do not treat this changelog as evidence of Google Fonts acceptance or completion of full Google Fonts QA.
